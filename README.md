# Система управления гостиничным комплексом (Hotel Management System)

Курсовой проект по дисциплине **«Среды визуального программирования»** (ВГТУ).  
Настольное кроссплатформенное приложение для автоматизации рабочего места администратора отеля: учет номерного фонда, дополнительных услуг, базы гостей и бронирований с контролем пересечения дат.

---

## Основные возможности

* **Управление номерным фондом (CRUD):**
  * Добавление, редактирование и удаление номеров различных категорий (*Стандарт*, *Комфорт*, *Люкс*, *Президентский*).
  * Контроль статуса комнаты (*Свободен*, *Ремонт*).
  * Защита от удаления номеров, к которым привязаны активные или будущие бронирования.
* **Оформление и управление бронированиями:**
  * Динамическая фильтрация доступных номеров на выбранные даты заезда и выезда (исключение номеров на ремонте и номеров с пересекающимися бронями).
  * Выбор дополнительных услуг из прайс-листа (связь «многие-ко-многим»).
  * Автоматический пересчет итоговой стоимости проживания (тариф номера × количество суток + сумма выбранных услуг).
  * Автоматическое завершение бронирований (`Завершено`) при наступлении даты выезда.
* **Учет гостей и аналитика истории визитов:**
  * Автоматическая идентификация существующих клиентов по серии и номеру паспорта (защита от дублирования записей).
  * Просмотр полной истории проживаний каждого гостя с подсчетом количества действительных визитов и общей суммы затрат.
* **Справочник дополнительных услуг:**
  * Добавление, изменение стоимости и удаление дополнительных платных опций отеля.
  * Автоматическое создание стартового набора номеров и услуг при первом запуске приложения.

---

## Технологический стек

* **Язык программирования:** C++17
* **Фреймворк:** Qt 6 (`Qt6::Widgets`, `Qt6::Sql`, `Qt6::Test`)
* **СУБД:** SQLite 3 (драйвер `QSQLITE`, автоматическая инициализация файла `hotel_management.db`)
* **Система сборки:** CMake 3.16+
* **Тестирование и покрытие:** Qt Test (`ctest`), `gcov` / `lcov`

## Требования для сборки

1. Компилятор с поддержкой стандарта **C++17** (GCC 9+, Clang, MinGW 8.1+ или MSVC 2019+).
2. Система сборки **CMake** версии 3.16 или выше.
3. Установленный фреймворк **Qt 6** (или Qt 5.15+) с компонентами `Widgets`, `Sql`, `Test`.

## Сборка и запуск

### Вариант 1: Через командную строку (Linux / macOS / Windows MinGW)

1. Клонируйте репозиторий и перейдите в каталог проекта:
   ```bash
   git clone https://github.com/username/hotel_management.git
   cd hotel_management
   ```

2. Сконфигурируйте проект с помощью CMake (при необходимости укажите путь к Qt через `-DCMAKE_PREFIX_PATH`):
   ```bash
   cmake -B build -DCMAKE_BUILD_TYPE=Release
   ```

3. Соберите исполняемые файлы приложения и тестов:
   ```bash
   cmake --build build
   ```

4. Запустите приложение:
   * **Linux / macOS:**
     ```bash
     ./build/hotel_management
     ```
   * **Windows:**
     ```cmd
     .\build\hotel_management.exe
     ```

### Вариант 2: Через IDE Qt Creator

1. Откройте **Qt Creator** и выберите `File` -> `Open File or Project...` (`Открыть файл или проект`).
2. Выберите файл `CMakeLists.txt` в корневой папке репозитория.
3. Выберите установленный комплект сборки (Kit) с **Qt 6** и нажмите `Configure Project`.
4. Нажмите `Ctrl + R` (или зеленую кнопку запуска) для компиляции и старта приложения.

## Модульное тестирование и замер покрытия кода

В проекте реализованы модульные тесты (`tst_hotel.cpp`) с использованием фреймворка `Qt Test`, проверяющие инициализацию БД, CRUD-операции, защиту от удаления занятых комнат, дедупликацию гостей по паспорту и алгоритм поиска свободных номеров при пересечении дат.

### Запуск тестов

Выполните команду в корневом каталоге проекта после сборки:

```bash
ctest --test-dir build --output-on-failure
```

Или запустите бинарный файл тестов напрямую для получения подробного лога `Qt Test`:

```bash
./build/hotel_tests
```

### Измерение покрытия кода логики (gcov / lcov)

Для сборки проекта с флагами профилирования и генерации отчета покрытия бизнес-логики (без классов GUI) выполните:

```bash
cmake -B build_cov -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS="--coverage" -DCMAKE_EXE_LINKER_FLAGS="--coverage"
cmake --build build_cov
ctest --test-dir build_cov --output-on-failure

lcov --capture --directory build_cov --output-file coverage.info
lcov --extract coverage.info "*/models.h" "*/dbmanager.h" "*/dbmanager.cpp" --output-file logic_coverage.info
lcov --list logic_coverage.info
```
