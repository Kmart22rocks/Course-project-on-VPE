Система управления гостиничным комплексом (HotelManagementSystem)

Курсовой проект по дисциплине «Среды визуального программирования». Приложение предназначено для учета номерного фонда, оформления бронирований, ведения базы гостей и дополнительных услуг отеля.

Описание функционала

В программе реализованы пять основных разделов:
- управление номерами (добавление, редактирование, удаление, смена статуса, защита от удаления занятых комнат);
- оформление и редактирование бронирований с проверкой свободных номеров на выбранные даты и выбором дополнительных услуг;
- база гостей с историей посещений, подсчетом общей суммы затрат и возможностью быстрого автозаполнения данных клиента при повторном бронировании;
- справочник платных услуг гостиницы;
- вкладка аналитики со столбчатой диаграммой выручки по категориям номеров, локальным обменом статистикой по TCP и загрузкой актуальных курсов валют (USD, EUR) по HTTP в формате JSON с сервера ЦБ РФ.

База данных SQLite (`hotel_management.db`) создается автоматически в папке с исполняемым файлом при первом запуске.

Используемые технологии

- C++17
- Qt 6 (модули Widgets, Sql, Network, Test)
- SQLite 3
- CMake 3.16+

Состав проекта

- `main.cpp` — точка входа и настройка внешнего вида приложения;
- `models.h` — структуры данных для номеров, гостей, услуг и бронирований;
- `dbmanager.h`, `dbmanager.cpp` — работа с базой данных SQLite;
- `bookingcalculator.h`, `bookingcalculator.cpp` — расчет стоимости проживания, статистики гостей и выручки;
- `currencyapiclient.h`, `currencyapiclient.cpp` — получение курсов валют по HTTP (JSON API ЦБ РФ);
- `networkservice.h`, `networkservice.cpp` — локальный TCP-сервер и TCP-клиент для передачи сводной статистики;
- `mainwindow.h`, `mainwindow.cpp` — главное окно программы;
- `bookingdialog.h`, `bookingdialog.cpp` — окно создания и редактирования бронирования;
- `guesthistorydialog.h`, `guesthistorydialog.cpp` — окно истории проживаний гостя;
- `analyticswidget.h`, `analyticswidget.cpp` — вкладка аналитики и отрисовка графика выручки;
- `tst_hotel.cpp` — модульные тесты на базе Qt Test;
- `CMakeLists.txt` — конфигурация сборки.

Сборка и запуск

Для сборки требуются компилятор с поддержкой C++17, CMake и установленный фреймворк Qt 6.

### Запуск через CLion или Qt Creator

1. Откройте папку с проектом (файл `CMakeLists.txt`) в среде разработки.
2. Дождитесь завершения конфигурации CMake.
3. Выберите цель сборки `HotelManagementSystem` и нажмите Run.

Если на Windows при запуске из IDE возникает ошибка отсутствия библиотек Qt, добавьте путь к папке `bin` вашего комплекта Qt (например, `D:\Qt\6.12.0\mingw_64\bin`) в переменную окружения `PATH` в настройках конфигурации запуска.

Сборка через консоль

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

После сборки исполняемый файл `HotelManagementSystem` (и `hotel_tests` для тестов) будет находиться в папке `build`.

Запуск тестов и проверка покрытия

Для запуска модульных тестов выберите цель `hotel_tests` в среде разработки или выполните в терминале:

```bash
ctest --test-dir build --output-on-failure
```

Для замера покрытия кода бизнес-логики (gcov) в CLion выберите цель `hotel_tests` и нажмите кнопку «Run 'hotel_tests' with Coverage». При сборке вручную из консоли используйте флаг `--coverage`:

```bash
cmake -B build_cov -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS="--coverage" -DCMAKE_EXE_LINKER_FLAGS="--coverage"
cmake --build build_cov
ctest --test-dir build_cov --output-on-failure
```
